Get started

Three steps. The first start of a runtime builds it and prepares its shaders; later starts are quick.

1. Install the tools

Rust and VS Build Tools with Desktop development with C++.

2. Run i95

Unzip the latest release and start i95.exe. Choose an output folder and your game folder.

3. Pick and play

Choose a runtime and a preset, then Play. On an 8 GB card use its 8gb or series_s preset.

Stays current

Runtimes move to their authors' newest commits without a new release; every change to launch settings is read first.

FAQ

Can I play GTA 6 on PC?

Not yet. These projects reach the game world, but at low frame rates and with missing graphics.

Is this a download or a crack?

No. There are no game files, keys or protection bypasses. You need your own copy of the Xbox Series game folder.

Why build from source?

Prebuilt "GTA 6 PC" exes are how fake ports spread malware. i95 compiles each runtime from a pinned commit you can read on GitHub, and leaves out any runtime that ships only a binary.

Does it work on Windows 10?

Not for every runtime: some need Shader Model 6.6, which Windows 10's built-in DirectX 12 lacks unless the runtime loads Microsoft's Agility SDK.

Whose work is this?

Mostly the runtime authors'. i95 is the launcher around them; see the credits.
